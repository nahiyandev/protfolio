# Md Nayem (Nahiyan Dev) — Portfolio

Personal portfolio website of **Md Nayem (Nahiyan Dev)**, Full Stack Developer
(Next.js, React, TypeScript & MERN) based in Mymensingh, Bangladesh.

🌐 **Live:** https://nahiyandev.vercel.app

## Features

- Animated hero section — profile photo with rotating rainbow beam ring,
  counter-rotating accent arc and ambient glow
- About, Skills, Projects, Experience, Education and Contact sections
- Featured project: **Bazar Dor** — daily commodity price tracker for Bangladesh
- Real projects only — every project links to its actual GitHub repository
- CV download button
- Dark modern theme, mobile-first responsive design
- SEO meta tags
